# Финни: игра про деньги для детей 7–14 лет

Сайт на Next.js 15. Русский и иврит (RTL), валюта ₪, все деньги в игре виртуальные.
Идеи из книг: «Богатый папа, бедный папа», «Атомные привычки», «Самый богатый человек в Вавилоне»,
«Психология денег», «Mindset». Из «48 законов власти» взяты только безопасные идеи (репутация, слово,
проверка, мышление на шаги вперёд), без манипуляций.

## Запуск

```bash
npm install
cp .env.example .env.local   # впишите ANTHROPIC_API_KEY
npm run dev                   # http://localhost:3000
```

Без ключа работают квесты, копилка, награды. Чат с Финни отвечает «Финни спит».

## Что внутри

- `/` главная: уровень, XP, серия дней, награды
- `/quest` один квест в день + офлайн-миссия + экран «на сегодня всё»
- `/chat` живой Финни (Claude API), лимит сообщений в день, лимит XP за чат
- `/dream` копилка мечты (игровые ₪)
- `/books` идеи из книг простыми словами
- `/parents` настройки, семейные миссии, что важно знать

## Безопасность

- Сообщения с картой, паролем, SMS-кодом, телефоном, email, адресом блокируются в браузере и на сервере
  (`lib/safety.ts`), в модель не уходят и в чате не показываются.
- Ключ API только на сервере (`app/api/finni/route.ts`). Лимиты запросов: `FINNI_DAILY_CAP`, `FINNI_HOURLY_PER_IP`.
  Лимит в памяти инстанса, для продакшена нужен Upstash или Supabase.
- Системный промпт: `lib/prompt.ts`. Тег `<xp>` из ответа модели вырезается и ограничивается 15 XP.
